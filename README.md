# 21 For 21

21 For 21 is a personal project to celebrate Maya's birthday with 21 letters from family and friends.

The main goal I want to achive is allow for people to access the site and leave a note for Maya for her birthday, choose a pixelated icon, and maybe a song to play when the message opens.

I have some features I want to start off with that will start from the bottom and work its way up. I also included additional features if I have time to create them.

### Main Features
- [X] Pink Background Color
- [X] Scrolling Background Multi-Colored Confetti
- [ ] Make the text and input text pixel themed either with a common font or downloading a new font. (For font and finding pixelated confetti, notebook page, etc. please find an image source and not create your own.)
- [ ] I want to have an element that after the login/intro/etc.. page where we get to the actual letters. With a pixel envelope image and a image of notebook paper that has scrollable text will pop out of it.
- [ ] Password Feature
- [ ] Ending Page with all of our names
- [ ] Save user data in CSV, this is where specific people and their messages will be kept. As well as song choices it it permits.
- [ ] Use React where the screen size doesn't matter. Meaning, login/intro, letters page, and ending page.
- [ ] Have two different paths. One path for people submitting letters for Maya, telling them why I built the website, a preview of how the page will look, and a "double check your letter feature". The other path for maya actual reading the letters going into a brief intro, letters, and all of our names page. 
- [ ] Host website online
